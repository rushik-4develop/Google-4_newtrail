# Sweet Dreams Cookie Shop Website 🍪

A beautiful, modern, and responsive website for a local cookie shop featuring an elegant design with warm colors and interactive animations.

## 🌟 Features

### Design & UI
- **Modern responsive design** that works on all devices
- **Beautiful color scheme** with warm cookie-inspired colors
- **Elegant typography** using Google Fonts (Playfair Display & Inter)
- **Smooth animations** and hover effects throughout
- **Interactive cookie animations** in the hero section

### Sections
1. **Hero Section** - Eye-catching landing with animated cookie showcase
2. **About Section** - Story of the cookie shop with brand values
3. **Menu Section** - Beautiful grid of cookie varieties with prices
4. **Contact Section** - Complete contact information and location details
5. **Footer** - Brand information and social media links

### Interactive Features
- **Smooth scrolling navigation** between sections
- **Fixed header** with transparent background that changes on scroll
- **Mobile-responsive menu** with hamburger toggle
- **Animated elements** that appear as you scroll
- **Interactive hover effects** on menu items and buttons
- **Ripple effect** on button clicks
- **Parallax scrolling** in hero section
- **Falling cookie crumbs** animation
- **Active navigation highlighting** based on scroll position

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Python 3 (for local development server) or any web server

### Running the Website

#### Option 1: Using Python's built-in server
```bash
# Navigate to the project directory
cd /workspace

# Start the development server
python3 -m http.server 8000

# Open your browser and go to:
# http://localhost:8000
```

#### Option 2: Using any web server
Simply serve the files through any web server (Apache, Nginx, etc.) or open `index.html` directly in your browser.

## 🔧 Customization

### Changing Colors
Edit the CSS custom properties in `styles.css`:
```css
:root {
    --primary-color: #d4906b;
    --secondary-color: #8b4513;
    /* ... other colors */
}
```

### Adding New Menu Items
1. Add a new menu item in the `menu-grid` section of `index.html`
2. Follow the existing structure with `.menu-item` class

### Modifying Content
- **Business Information**: Update contact details in the contact section
- **About Story**: Modify the about section text
- **Social Media**: Update social media links in the footer
